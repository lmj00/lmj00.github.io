### 개요
인터넷 프로토콜(IP)은 **패킷 교환 컴퓨터 통신 네트워크**들이 상호 연결된 시스템(케테넷)에서 사용되도록 설계되었다. 그 핵심 임무는 **데이터그램**이라는 데이터 블록을 출발지 호스트에서 목적지 호스트로 전달하는 것이다. 이 프로토콜은 엔드투엔드 데이터 신뢰성, 흐름 제어, 순서화 등의 서비스를 제공하지 않는 **최소주의적 범위**에 한정되어 있으며, 이를 통해 다양한 지원 네트워크의 서비스 품질을 활용할 수 있다.

### 프로토콜 계층 구조 내 위치
IP는 프로토콜 계층 구조에서 상위 계층과 하위 계층 사이의 중개자 역할을 한다.

![diagram](/assets/diagrams/2026-08-11-인터넷-프로토콜-ip-의-기본-개념과-동작-모델-1.svg)

상위의 **호스트 대 호스트 프로토콜**(예: TCP, UDP)은 인터넷 환경에서 IP를 호출한다. 반대로 IP는 다음 게이트웨이 또는 목적지 호스트로 인터넷 데이터그램을 운반하기 위해 **로컬 네트워크 프로토콜**을 호출한다. 예를 들어, TCP 모듈은 TCP 세그먼트를 IP 데이터그램의 데이터 부분으로 삼아 IP 모듈을 호출하며, 주소 등의 매개변수를 인자로 제공한다. IP 모듈은 데이터그램을 생성한 후 로컬 네트워크 인터페이스를 호출해 전송한다.

### 동작 모델과 데이터그램 전송 경로
IP 모듈은 인터넷 통신에 관여하는 모든 호스트와 네트워크를 연결하는 게이트웨이에 상주한다. 이들은 주소 필드 해석과 데이터그램 단편화/재조립에 대한 공통 규칙을 공유하며, 게이트웨이에서는 경로 결정 등의 절차를 추가로 가진다.

### 핵심 기능과 메커니즘
IP의 기본 기능은 **주소 지정(Addressing)**과 **단편화(Fragmentation)** 두 가지이다. 주소 지정은 인터넷 헤더에 담긴 주소를 사용해 데이터그램을 목적지로 전달하며, 이 경로 선택 과정을 **라우팅**이라고 한다. 단편화는 "작은 패킷" 네트워크를 통과해야 할 때 긴 데이터그램을 나누고 재조립하기 위해 헤더 필드를 사용한다.

서비스 제공을 위해 IP는 네 가지 키 메커니즘을 사용한다.

| 메커니즘 | 목적 | 주요 특성 |
| :--- | :--- | :--- |
| **서비스 유형(Type of Service)** | 원하는 서비스 품질 표시 | 게이트웨이가 특정 네트워크의 전송 매개변수, 다음 홉 네트워크 또는 게이트웨이를 선택하는 데 사용하는 추상화된 매개변수 집합. |
| **생존 시간(Time to Live)** | 데이터그램 수명 상한 설정 | 발신자가 설정하며, 경로상 처리 지점에서 감소. 0에 도달하면 데이터그램 파기. 자가 파괴 시간 제한으로 간주. |
| **옵션(Options)** | 특정 상황에 필요한 제어 기능 | 타임스탬프, 보안, 특수 라우팅 등을 위한 규정 포함. 일반 통신에는 불필요할 수 있음. |
| **헤더 체크섬(Header Checksum)** | 처리용 헤더 정보 전송 정확성 검증 | 체크섬 실패 시 오류를 감지한 개체가 즉시 데이터그램 폐기. **데이터 자체의 오류는 검사하지 않음**. |

### 프로토콜의 특성과 한계
IP는 **비연결형** 프로토콜이다. 각 인터넷 데이터그램은 다른 데이터그램과 무관한 독립적 개체로 취급되며, 연결이나 가상 회로가 존재하지 않는다. 이에 따라 몇 가지 근본적인 한계를 가진다.

*   **신뢰성 부재**: 엔드투엔드 또는 홉바이홉 확인응답이 없다.
*   **데이터 오류 제어 부재**: 헤더 체크섬만 있을 뿐, 데이터에 대한 오류 제어는 없다.
*   **재전송 부재**: 패킷 손실 시 재전송 메커니즘이 없다.
*   **흐름 제어 부재**: 수신자 처리 속도를 고려한 전송 속도 조절이 없다.

발견된 오류는 **인터넷 제어 메시지 프로토콜(ICMP)**을 통해 보고될 수 있으며, ICMP는 IP 모듈 내에 구현되어 있다.

### 정리
1.  IP는 패킷 교환 네트워크 간 연결을 위한 **비연결형 데이터그램 전송 프로토콜**이다.
2.  프로토콜 스택에서 **전송 계층과 링크 계층 사이**에서 중개 역할을 하며, 주소 지정과 단편화/재조립이 핵심 기능이다.
3.  서비스 유형, 생존 시간, 옵션, 헤더 체크섬 네 가지 메커니즘을 통해 기본 서비스를 제공한다.
4.  **신뢰성, 순서 보장, 흐름 제어, 데이터 오류 정정을 전혀 제공하지 않는다.** 이러한 서비스는 상위 계층(예: TCP)이 담당해야 한다.
5.  데이터그램 전송은 호스트와 게이트웨이에 상주하는 IP 모듈이 로컬 네트워크 프로토콜을 차례로 호출하며 이루어진다.
