### 개요
PostgreSQL은 데이터베이스 서버 자체의 운영과 관리를 위한 일련의 **서버 애플리케이션**을 제공한다. 이 유틸리티들은 데이터베이스 클러스터의 생성, 시작/정지, 상태 점검, 복구, 업그레이드 등 서버의 생명주기와 내부 구조를 직접 다루는 도구들이다. 이들은 **데이터베이스 서버가 상주하는 호스트에서만 유용하게 실행될 수 있다**는 점이 특징이며, 클라이언트 측에서 사용하는 애플리케이션과는 구분된다.

### 서버 애플리케이션의 종류와 역할
공식 문서는 서버 애플리케이션을 크게 13개의 주요 유틸리티로 나열하고 있다. 각 유틸리티는 데이터베이스 시스템의 특정 측면을 전문적으로 관리한다.

**클러스터 초기화 및 서버 제어**
*   `initdb`: 새로운 PostgreSQL **데이터베이스 클러스터**를 생성하는 최초의 도구이다. 클러스터란 단일 서버 인스턴스가 관리하는 데이터베이스들의 집합을 말한다.
*   `postgres`: PostgreSQL **데이터베이스 서버** 프로세스 자체이다. 이 프로세스가 실제로 클라이언트 연결을 수락하고 쿼리를 처리한다.
*   `pg_ctl`: 서버 프로세스의 **초기화, 시작, 정지, 재시작, 상태 확인** 등을 제어하는 관리 도구이다.

**Write-Ahead Log(WAL) 및 복제 관리**
WAL(Write-Ahead Log)은 트랜잭션의 지속성과 복구를 보장하는 핵심 메커니즘이다. 여러 도구들이 WAL과 관련된 작업을 담당한다.
*   `pg_waldump`: WAL 파일의 내용을 사람이 읽을 수 있는 형태로 출력하여, 내부에서 어떤 작업이 기록되었는지 분석할 수 있게 한다.
*   `pg_resetwal`: WAL과 다른 제어 정보를 재설정한다. 주로 WAL 손상 등 복구 불가능한 상황에서 최후의 수단으로 사용된다.
*   `pg_archivecleanup`: WAL 아카이브 파일을 정리(삭제)한다. 로그 샤이핑(Log Shipping) 복제나 PITR(Point-in-Time Recovery) 설정에서 오래된 아카이브 로그를 관리할 때 필요하다.
*   `pg_createsubscriber`: **물리적 복제본**을 새로운 **논리적 복제본**으로 변환하는 도구이다. 이는 복제 전략을 변경할 때 사용될 수 있다.
*   `pg_rewind`: 한 데이터 디렉토리가 다른 데이터 디렉토리에서 분기(fork)된 후, 두 디렉토리를 다시 동기화한다. 주로 스트리밍 복제에서 장애 조치 후 이전 주 서버를 새 주 서버의 복제본으로 빠르게 전환할 때 유용하다.
*   `pg_walsummary`: WAL 요약 파일의 내용을 출력한다. 이는 증분 백업 등에서 변경된 데이터 블록을 효율적으로 식별하는 데 사용된다.

**진단 및 성능 측정**
*   `pg_checksums`: 데이터베이스 클러스터 내 데이터 페이지에 대한 **체크섬**을 활성화, 비활성화 또는 검사한다. 체크섬은 저장된 데이터의 무결성(손상 여부)을 확인하는 데 사용된다.
*   `pg_controldata`: 데이터베이스 클러스터의 **제어 정보**를 표시한다. 제어 정보는 클러스터의 전반적인 상태(예: 최신 체크포인트 위치, 데이터베이스 레이아웃 버전 등)를 담고 있는 메타데이터이다.
*   `pg_test_fsync`: 시스템에서 가장 빠른 `wal_sync_method`(WAL 동기화 방법)를 결정하기 위해 파일 시스템의 동기화 성능을 측정한다.
*   `pg_test_timing`: 시스템의 타이밍 오버헤드를 측정한다. 정확한 성능 프로파일링과 모니터링을 위해 중요하다.

**업그레이드**
*   `pg_upgrade`: 기존 PostgreSQL 서버 인스턴스를 더 새로운 메이저 버전으로 **업그레이드**한다. 데이터 디렉토리를 새 버전 형식으로 변환하는 작업을 수행한다.

### 정리
*   PostgreSQL 서버 애플리케이션은 데이터베이스 서버 호스트에서 실행되는 저수준 관리 도구들의 모음이다.
*   이들은 데이터베이스 클러스터의 생성(`initdb`), 서버 프로세스 제어(`pg_ctl`, `postgres`), WAL 관리 및 복구(`pg_waldump`, `pg_resetwal`, `pg_rewind`), 데이터 무결성 점검(`pg_checksums`), 시스템 성능 측정(`pg_test_fsync`), 그리고 버전 업그레이드(`pg_upgrade`) 등 광범위한 운영 작업을 담당한다.
*   각 도구는 특화된 목적을 가지며, 데이터베이스 관리자가 시스템의 내부 동작을 이해하고 문제를 진단하며 효율적으로 운영하는 데 필수적이다.
